# CarePlus Medical Center Website

A modern, responsive healthcare website concept for clinics, hospitals, and medical professionals. The design focuses on clear navigation, approachable medical information, and a simple appointment-request experience.

## Live Preview
Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)** to publish the website.

## Features
- Responsive layout for desktop, tablet, and mobile
- Modern healthcare-focused visual design
- About, services, doctor profiles, and contact sections
- Appointment request form with browser-side validation
- Mobile navigation menu
- Accessible form labels and status messaging
- Lightweight HTML, CSS, and vanilla JavaScript

## Built With
- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started
1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a browser, or use a local development server.
4. Customize the clinic name, contact details, service information, doctor profiles, and images before publishing.

## Important Demo Notes
- The clinic, doctor names, address, phone number, and email are sample content for demonstration. Replace them with verified information before production use.
- The appointment form is front-end only. It does not transmit or store patient information. Connect it to a secure, privacy-compliant backend before accepting real appointments.
- External images are loaded from Unsplash and Google Fonts require an internet connection.

## Customization
Update the CSS variables at the top of `style.css` to change the color palette. Edit the content in `index.html` to adapt the website to a real healthcare provider.
